# Simple Calculator (Webpack Build)

Веб-приложение — калькулятор с поддержкой основных арифметических операций (сложение, вычитание, умножение, деление, процент, смена знака) и переключением между светлой и тёмной темой.

![Скриншот приложения, светлая тема](./assets/Simple%20Calculator%20light-theme.png)
![Скриншот приложения, тёмная тема](./assets/Simple%20Calculator%20dark-theme.png)

Сборка проекта выполнена с использованием Webpack, ESLint, Prettier.

## Возможности:

- поддержка базовых операций: +, −, ×, ÷
- вычисление процентов и изменение знака числа (+/-)
- переключение между светлой и тёмной темой
- оптимизированная сборка с минификацией JS/CSS
- настроены линтеры и прекоммиты для чистоты кода

### Структура проекта:

``` SIMPLE CALCULATOR/
│
├── .husky/ - cкрипты для Git hooks (pre-commit с линтингом)
│  
├── dist/ - cборка проекта (результат после билда)
│ ├── index.html - компилированный HTML-файл
│ ├── main.css - минифицированный CSS (результат style.css)
│ └── main.js - минифицированный JavaScript (результат index.js)
│
├── node_modules/ - установленные зависимости npm
│
├── src/ - исходники приложения
│ ├── index.js - основная логика работы приложения
│ ├── style.css - основные стили приложения
│ └── template.html - HTML-шаблон для Webpack HtmlWebpackPlugin
│
├── .gitignore - исключения для Git
├── .prettierrc - конфигурация форматирования Prettier
├── eslint.config.js - настройки линтера ESLint
├── package.json - настройки npm
├── package-lock.json - зафиксированные версии всех установленных пакетов, читаемые npm
└── webpack.config.cjs - основная конфигурация Webpack
```

#### Основные технологии:

- HTML5 - разметка калькулятора
- CSS3 (Flexbox) - вёрстка и стилизация
- JavaScript (ES6) - логика калькулятора
- Webpack - сборка, минификация и подключение модулей
- ESLint - анализ и исправление ошибок в коде
- Prettier - форматирование кода
- Husky - автоматические проверки при коммитах
